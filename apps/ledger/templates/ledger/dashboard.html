Examiner notes

Why a retry does not double-charge

The same idempotency key and request body replay the stored response. The transfer operation is performed once; subsequent matching requests return the persisted result.

Locking strategy

SELECT FOR UPDATE locks wallets by ascending UUID inside an atomic database transaction, reducing deadlocks while serializing concurrent balance changes.

Double-entry audit

Each successful transfer writes a debit and matching credit. The invariant banner compares database aggregate totals; a green state means total debits equal total credits.
